# Global Military Areas

Global dataset of military areas extracted from [OpenStreetMaps](https://www.openstreetmap.org/) and other sources. 

--------
- Mapbox vector tiles
- Gzip-Compressed
- Zoom levels 0-11
- Generated `03-09-2026`
  
Example: `https://cdn.jsdelivr.net/gh/Levanada/ol-military-bases@main/tiles/{z}/{x}/{y}.pbf`

--------

See the [Manifest](./manifest.json) for more technical info.
